### 🎣 Fishing Mini Game Mod
Replaces standard fishing with a moving target bar minigame.
Press A when the line crosses the fish!

## 🛠️ How to Install

1. Download the `.zip` file for the mod.
2. Open **Gen1Recomp**.
3. Go to the **Mods** menu and select **Import mod.zip**.
4. Choose the `.zip` file and make sure it is enabled!
5. Choose whether you want Advanced colours or not in the Mod menu. 
6. Restart is needed after enabling/disabling in the in-game Mods menu.
